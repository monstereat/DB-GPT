# 电商演示数据字典

本目录使用合成数据，仅用于本地安全演示和回归评测。金额字段统一以人民币分为单位；时间字段使用 ISO `YYYY-MM-DD`。租户隔离范围由服务端策略决定，不能由问题文本或候选 SQL 设置。

机器可读的表、字段、敏感级别、租户键和关系定义见 [`schema_metadata.json`](schema_metadata.json)。演示执行器从该文件生成列白名单，数据库表结构测试会将字段及复合外键与元数据逐项比对。该元数据只登记本地合成 SQLite 源，不包含生产连接凭据或企业数据源审批流程。

销售额、已支付退款额、净销售额和退款率的机器可读版本目录见 [`metric_catalog.json`](metric_catalog.json)。ReAct Agent 通过服务端 `DBGPT_DATABASE_CONTEXT_FILES` 加载本文件，因此这里同步列出 Agent 需要遵守的口径；实际指标查询 API 仍只接受目录登记的指标与维度。

## 表关系

```text
regions 1 ── n users
regions 1 ── n orders
users   1 ── n orders
orders  1 ── n order_items
products 1 ── n order_items
orders  1 ── n refunds
```

所有业务表均包含 `tenant_id`。外键使用 `(tenant_id, id)` 复合键，阻止不同租户的记录建立关联。执行器按服务端租户范围为每张表建立连接级只读视图。

## 表和字段

| 表 | 业务含义 | 可查询字段 | 敏感或内部字段 |
| --- | --- | --- | --- |
| `users` | 买家资料 | `user_id`、`region_id` | `full_name`、`email`、`phone` |
| `regions` | 销售区域维度 | `region_id`、`name`、`area` | 无 |
| `products` | 商品及品类维度 | `product_id`、`product_name`、`category`、`list_price_cents` | `internal_cost_cents` |
| `orders` | 订单主表；`total_cents` 是订单金额 | `order_id`、`user_id`、`region_id`、`created_at`、`status`、`total_cents` | `internal_note` |
| `order_items` | 订单商品明细；行金额为 `quantity * unit_price_cents` | `item_id`、`order_id`、`product_id`、`quantity`、`unit_price_cents` | 无 |
| `refunds` | 退款记录；`amount_cents` 是退款金额 | `refund_id`、`order_id`、`created_at`、`amount_cents`、`status` | `internal_note` |

## 指标口径

- **销售额 1.0.0（默认）**：按 `orders.created_at` 的左闭右开期间统计 `status = 'completed'` 订单 `total_cents` 之和；取消订单不计入，单位为人民币分。
- **已支付退款额 1.0.0（默认）**：按 `refunds.created_at` 的左闭右开期间统计 `status = 'paid'` 退款 `amount_cents` 之和。
- **已支付退款额 2.0.0**：按关联订单的 `orders.created_at` 归属期间，统计这些订单对应的已支付退款；用于订单 cohort 分析，不受退款实际发生日期影响。
- **净销售额 1.0.0（默认）**：销售额 1.0.0 减去已支付退款额 1.0.0；无退款时按零退款计算。
- **净销售额 2.0.0**：销售额 1.0.0 减去已支付退款额 2.0.0，按原订单 cohort 统计。
- **退款率 1.0.0（默认）**：已支付退款额 1.0.0 除以销售额 1.0.0。
- **退款率 2.0.0**：已支付退款额 2.0.0 除以销售额 1.0.0，按原订单 cohort 统计。
- **毛利率 1.0.0（默认）**：按订单日期统计已完成订单明细；销售额为 `quantity * unit_price_cents`，商品成本为 `quantity * products.internal_cost_cents`，毛利率为 `(销售额 - 成本) / 销售额 * 100`；退款不冲减，销售额为零时返回空值。仅 `admin` 可通过已发布指标查询该派生比率。
- 以上退款指标按区域归因时均关联原订单的 `region_id`；派生指标必须沿用上述固定依赖版本。若问题未指定版本，使用目录默认版本；不得把 1.0.0 与 2.0.0 混算。
- 退款率和毛利率分母为零时结果未定义，返回空值而不是 `0`。内部成本仍标记为机密且原始 SQL 不可查询；成本只在服务端生成、角色受限的毛利率指标计划中用于计算，不会作为结果字段返回。
- **时间范围**：季度使用左闭右开区间，例如 2026 年第二季度为 `>= '2026-04-01' AND < '2026-07-01'`。
- **演示默认年份**：服务端指标目录声明 `default_year: 2026`。问题明确给出季度或月份但省略年份时，指标路由使用这个目录默认值；问题没有给出可识别的时间范围时仍需补充时间条件。该默认仅适用于此合成电商目录，不是所有数据源的全局默认。
- **区域过滤**：服务端目录将“华南 / 华南区 / South China”映射到已发布区域值 `South China`。只支持目录明示的区域别名；具体城市筛选或未登记区域不会被当成无范围的汇总指标。
- 按地区分组的指标结果按指标值降序，同值时按区域名排序；按月份分组保持年月升序。
- **商品销售额**：完成订单明细的 `quantity * unit_price_cents` 汇总；取消订单明细不计入。

## 多轮问答规则

- 只在同一 DB-GPT conversation 和同一已授权数据源内继承上下文；OIDC 身份或数据源切换后按新会话处理。服务端每次请求仍须单独校验权限，历史对话不能扩大授权范围。
- 追问中的“其中”“这些订单”“哪个城市”等指代，继承本轮对话最近一次明确的日期范围、区域范围和指标版本。上下文缺失或多个条件互相冲突时先向用户澄清，不要自行补默认条件。
- “哪个城市退款率最高”按城市分别计算：分子为同一日期范围内、状态为 `paid` 且归属到原订单城市的退款额；分母为该城市同一范围内状态为 `completed` 的订单销售额。默认退款口径为 1.0.0（按退款发生日期）；有销售额但没有已支付退款时退款率为 0，销售额为 0 时结果未定义。按退款率降序排序，同率时按城市名称排序。
- 查询只返回当前身份可访问的行和字段；提示上下文不得覆盖数据库 Schema、只读策略、租户或区域授权。

## 访问规则

`tenant_id`、个人姓名、邮箱、电话、商品内部成本和备注字段不得作为原始查询结果返回给 Agent。毛利率是唯一的内置受限成本指标，仅 `admin` 可使用确定性指标编译路径得到派生比率。SQLite 示例通过连接级授权器和受限视图演示该规则。生产环境必须使用真实身份提供方、数据库只读凭据及对应数据库的权限策略；此演示数据和当前仓库的模拟认证不构成生产安全边界。
